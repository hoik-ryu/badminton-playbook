# 튜토리얼 콘텐츠 검수 체크리스트 (PRD r7 7.3 ③, 개발용)

이 폴더의 `<stage_id>.json`은 서버가 내려주는 튜토리얼 콘텐츠입니다(사용자 결정 2026-11-19 D-T1, `docs/workflow-proposals/tutorial-mvp-implementation-plan.md`).

- 형식·정합성은 자동 검사가 맡습니다(`app/modules/tutorial/content.py`의 `validate_content`, 테스트 `tests/modules/test_tutorial_content.py`, AC-117).
- **전술 정확성은 자동 검사로 확인하지 않습니다.** 제품 소유자가 아래 체크리스트로 검수합니다. 검수 기록은 콘텐츠 데이터 안에 두지 않고 이 파일에만 둡니다(PRD 7.3).
- **하나라도 체크되지 않은 스테이지는 배포하지 않습니다(릴리스 기준 5).**

## 현재 상태(2026-11-19): 모든 스테이지 미검수 — 배포 금지

현재 8개 파일은 **디자인 Preview의 흐름 확인용 예시 데이터**(`design-preview/src/mock/tutorialFlow.ts`)를 데이터 구조 검증용으로 옮긴 **초안**입니다. 실제 학습 콘텐츠로 확정되지 않았습니다. 알려진 문제:

- 같은 과정의 스테이지들이 같은 5개 상황을 그대로 씁니다(왕초급 1·2·3, 초급 1·2·3, 입문자 1·2). 스테이지별 학습 목표(C-27)를 다루지 않습니다 → ① 위반
- 모든 상황에서 셔틀 도착 칸 = 정답 칸입니다. 왕초급·초급 스테이지마다 '셔틀콕 방향 칸 ≠ 정답 칸' 상황이 1개 이상 필요합니다 → ② 위반
- 해설이 칸 위치를 되풀이하는 일반 문장입니다(왜 그 위치인지 전술 근거가 없음) → ③ 미충족
- 시작 배치(나·파트너·상대)가 모든 상황에서 같습니다 → ② '5개 상황은 서로 달라야 함' 위반
- 입문자 2단계('기본 자리와 복귀')가 1단계와 같은 번호 이동 문제입니다

콘텐츠를 고칠 때는 스테이지 ID의 버전을 올립니다(`<과정>-<순번>-v2`, C-28). 레지스트리(`../stage_registry.json`)와 프런트 Mock 사본(`frontend/src/features/tutorial/mockRegistry.ts`)도 함께 바꿉니다.
