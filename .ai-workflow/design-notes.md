## 분석

- 기준: planning r2(승인됨, 시작 커밋 `99cd9f7`). 기획 문서 02–05와 PRD 7.1의 확정 사항 C-01–C-12를 읽었습니다.

### 이미 확정된 사항(다시 묻지 않음)

- **플랫폼**: 운영진 화면은 PC·모바일 반응형(NFR-001). 회원 화면(학습, 퀴즈, 마이페이지, 가입, 로그인)은 모바일 레이아웃만 만들고, PC에서는 가운데 정렬한 최대 480px로 보여 줍니다(NFR-002, ASM-017).
- **역할과 메뉴**: 회원은 학습·마이페이지만 봅니다. 운영진은 운영 메뉴(명단, 대진, 청백전, 가입 승인)를 함께 보고, 슈퍼 관리자는 역할 관리까지 봅니다(AC-003, FR-003). 운영진도 회원 기능을 씁니다(ASM-020).
- **로그인**: 카카오 로그인만 씁니다(C-08). 처음 로그인하면 이름과 성별을 입력하고, 상태는 '승인 대기'가 됩니다(FLOW-001-S1, AC-001). 승인 대기·거절·비활성 계정에는 계정 상태 안내를 보여 줍니다(FLOW-001-S4a, AC-004, AC-058).
- **점수 노출**: 1–10 점수는 운영진 이상만 봅니다. 회원 권한의 화면과 API에는 나오지 않습니다(FR-006, NFR-005, AC-017).
- **대진 흐름**: 세션 열기 → 참석 체크 → 옵션 → 생성 → 검토·다시 생성 → 확정 → 라운드 완료 → 참석 변경 → 다음 라운드 → 세션 종료(FLOW-004). 라운드는 4경기가 모두 끝나면 한꺼번에 완료합니다(FLOW-004-S7).
- **대진 규칙**: 생성 방식은 레벨별·무작위 중 하나이고 항상 하나가 선택돼 있습니다(AC-022). 규칙 4가지는 각각 켜고 끄며, 다음 라운드에서도 같은 옵션이 기본값입니다(AC-023, FLOW-004-S3). 규칙 정의와 완화 순서는 C-01–C-05와 FR-010을 따릅니다.
- **생성 결과**: 코트 수(기본 4, 세션 중 변경 불가, C-06)만큼 경기를 만들고 남는 인원은 대기자로 둡니다(FR-009). 4명 미만이면 생성하지 않습니다(AC-026). 진행 중인 라운드가 있으면 다음 라운드를 생성할 수 없습니다(AC-039). 확정하면 재생성과 교체가 비활성화됩니다(AC-037).
- **동시 조작**: 확정하거나 저장할 때 충돌을 감지하고, 안내와 함께 최신 상태를 다시 불러옵니다(C-10, AC-056).
- **청백전**: 일반 세션과 따로 관리합니다(AC-042). 경기는 청팀 2명 대 백팀 2명만 가능합니다(AC-043). 승패만 기록하고 수정할 수 있으며, 스코어 입력란은 없습니다(AC-044). 게스트도 참가하지만 랭크는 받지 않습니다(C-09).
- **랭크**: 10경기 이상, S/A/B/C 기준은 70/55/40%, 전체 누적입니다(C-07). 경기 수가 모자라면 '랭크 없음'과 남은 경기 수를 보여 줍니다(AC-046).
- **학습·퀴즈**: 4개 주제, 코트 다이어그램과 애니메이션, 재생·일시정지·다시 보기(AC-048). 답을 고르면 바로 정답과 해설을 보여 주고, 결과는 저장하지 않습니다(AC-051, AC-052).
- **범위 제외(PRD 6장)**: 회원 앱과 알림, 일반 게임 승패 기록, 전체 랭킹 보드, 청백전 스코어, 회원이 자기 점수를 보는 기능, 학습 콘텐츠 편집, 회원이 직접 참석 등록하는 기능(비목표). 이런 요청이 나오면 PF로 분리합니다.

3. **회원 명단·게스트·점수** (FLOW-003 / US-005–007, US-020): 점수 노출 규칙(NFR-005)
4. **청백전과 랭크** (FLOW-005 / US-014–016)
5. **로테이션 학습과 퀴즈** (FLOW-006 / US-017–018)

### 주제별 미결정 UX 항목(기획에 답이 없는 것)

1. **실시간 대진**: 주로 쓰는 기기, 세션 화면 구조(단계형/한 화면/탭), 참석 체크 목록 방식, 코트 카드에 보여 줄 정보, 대기자 표시, 지난 라운드 이력 보기, 확정·완료·종료 전 확인 단계, 다시 생성할 때 이전 결과 비교, 완화 표시 형태(Should), 수동 교체 조작(Should), 충돌 안내 형태
2. **가입·로그인·내비게이션**: 운영진이 회원 화면(모바일 전용)과 운영 화면(반응형)을 오가는 구조, 로그인 첫 화면 구성, 계정 상태 안내 화면, 가입 승인 목록의 처리 방식(개별/일괄), 역할 관리 확인 단계
3. **명단·게스트·점수**: 회원과 게스트를 탭으로 나눌지 한 목록에 둘지, 점수 입력 컨트롤, '점수 미설정' 강조, 비활성 회원 표시·필터
4. **청백전**: 목록·상세 구조, 팀 편성 방식, 경기 편성 입력, 승패 입력 방식
5. **학습·퀴즈**: 주제 목록 형태, 애니메이션 컨트롤 배치, 퀴즈 진행 방식(한 문제씩/목록)
6. **마이페이지**: 랭크·전적 강조 방식, 프로필 수정 방식

## 라운드 1 — 실시간 대진(화면 골격)
- **상태**: 답변 완료
### 질문
#### R01-Q1: 현장에서 대진을 주로 운영하는 기기
- **선택지**: a) 휴대폰 위주(모바일 화면을 기준으로 설계하고 PC에서는 넓게 펼침) / b) PC·태블릿 위주(넓은 화면을 기준으로 설계하고 모바일은 축약) / c) 둘 다 비슷하게 씀
- **권장안**: a) — 체육관에서 운영진이 코트 사이를 오가며 참석 확인, 대진 생성, 라운드 완료를 처리하므로 한 손 조작을 기준으로 잡는 편이 안전합니다. 반응형 요구(NFR-001)는 PC에서 같은 화면을 넓게 펼쳐 충족합니다.
- **관련**: NFR-001, FLOW-004, US-008, US-010
#### R01-Q2: 운동 세션 화면 구조
- **선택지**: a) 단계형(참석 → 옵션 → 대진을 순서대로 넘기는 화면) / b) 대진 중심 한 화면(현재 라운드 코트 카드가 메인이고, 참석과 옵션은 버튼으로 여는 패널. 모바일은 하단 시트, PC는 옆 패널) / c) 탭 3개(참석 / 옵션 / 대진)
- **권장안**: b) — 운동 중에는 생성 → 확정 → 완료가 라운드마다 반복되고(FLOW-004-S4–S8), 참석은 라운드 사이에만 가끔 바뀌며(FLOW-004-S8), 옵션은 다음 라운드에도 그대로 유지됩니다(AC-023). 가장 자주 하는 행동이 첫 화면에 있어야 합니다. 첫 라운드 전에는 참석 패널이 자동으로 열리게 합니다.
- **관련**: FLOW-004-S1, FLOW-004-S3, FLOW-004-S8, US-008, US-009, US-012, AC-023
#### R01-Q3: 코트 카드에 보여 줄 선수 정보
- **선택지**: a) 이름만 / b) 이름 + 성별 표시 / c) 이름 + 성별 + 1–10 점수 + 팀 점수 합 / d) c에 더해 오늘 게임 수
- **권장안**: c) — 운영진은 다시 생성할지 판단하려고(FLOW-004-S5) 밸런스(C-02)와 성별 조합(C-03) 결과를 확인해야 합니다. 점수는 운영진 전용 화면이므로 노출 규칙(FR-006, NFR-005)에도 맞습니다. 게임 수는 공평성 규칙(C-04)이 자동으로 맞추고, 카드가 복잡해지므로 대기자 목록에서만 보여 줍니다.
- **관련**: FLOW-004-S5, US-010, FR-006, NFR-005, C-02, C-03, AC-030
#### R01-Q4: 참석 체크 목록 방식
- **선택지**: a) 이름순 목록 하나 + 검색, 게스트는 아래에 따로 구분 / b) 남·여로 나눈 두 목록 / c) 최근 참석한 사람을 위에 두는 정렬
- **권장안**: a) — 회원 18명 안팎을 체크하는 규모(AC-019)라 한 목록 스크롤과 검색이면 충분하고, 순서가 늘 같아야 빨리 찾습니다. 성별 분포는 목록 위에 따로 보여 주고(FLOW-004-S2), 게스트는 '게스트'로 구분해 표시합니다(AC-012).
- **관련**: FLOW-004-S2, US-008, AC-019, AC-012

## 라운드 2 — 실시간 대진(진행 중 화면과 예외)
- **상태**: 답변 완료
### 질문
#### R02-Q1: 대기자와 지난 라운드를 보여 주는 위치
- **선택지**: a) 메인 화면에서 코트 카드 아래에 대기자 섹션을 두고(이름, 성별, 오늘 게임 수), 그 아래에 지난 라운드 목록을 접어 둠 / b) 메인에는 대기자만 두고, 지난 라운드는 별도 '오늘 기록' 화면으로 분리 / c) 메인 화면을 '현재 라운드 / 대기자 / 지난 라운드' 탭으로 나눔
- **권장안**: a) — 대기자는 다음 라운드에 우선 배정되므로(FR-009, C-04) 운영진이 현재 라운드와 함께 봐야 합니다. 게임 수는 대기자 목록에서 보여 주기로 했습니다(UXD-003). 지난 라운드는 가끔 확인하는 정보라 접어 두면 대진 중심 한 화면(UXD-002)을 유지할 수 있습니다.
- **관련**: FLOW-004-S4, FLOW-004-S7, FR-009, FR-012, US-010, US-012, AC-024, C-04
#### R02-Q2: 되돌릴 수 없는 행동 전 확인 단계
- **선택지**: a) '확정', '라운드 완료', '세션 종료' 모두 확인 창을 띄움 / b) '세션 종료'만 확인 창을 띄우고, 확정과 라운드 완료는 바로 처리 / c) 확인 창 없이 모두 바로 처리
- **권장안**: a) — 세 행동 모두 기획상 되돌릴 수 없습니다. 확정하면 대진을 바꿀 수 없고(AC-037), 완료하면 이력이 쌓이며(FR-012), 종료하면 라운드를 더 만들 수 없습니다(FLOW-004-S9). 휴대폰 한 손 조작(UXD-001)에서는 잘못 누를 위험이 큽니다. 라운드마다 확인 창이 두 번 뜨지만, 짧은 한 줄 확인으로 부담을 줄입니다.
- **관련**: FLOW-004-S6, FLOW-004-S7, FLOW-004-S9, FR-011, FR-012, AC-037, AC-038
#### R02-Q3: 규칙 완화 표시 형태(Should)
- **선택지**: a) 완화된 경기의 코트 카드에 배지만 표시(예: '성별 완화'), 배지를 누르면 설명 / b) a에 더해 대진 위쪽에 한 줄 요약(예: '2경기에서 규칙 완화') / c) 코트 카드 아래에 완화 내용을 문장으로 바로 표시
- **권장안**: b) — 휴대폰에서는 코트 카드 4개가 세로로 이어져 아래쪽 카드의 배지를 놓치기 쉽습니다. 위쪽 요약으로 먼저 알리고, 카드 배지로 어느 경기인지 보여 줍니다. 완화가 없으면 아무것도 표시하지 않습니다(AC-041).
- **관련**: FLOW-004-S4c, FR-013, US-013, AC-041, AC-061, C-03
#### R02-Q4: 선수 수동 교체 조작(Should)
- **선택지**: a) 선수를 누른 뒤 바꿀 상대를 누름(탭-탭) / b) 드래그 앤 드롭 / c) 선수를 누르면 하단 시트에 바꿀 수 있는 대상(대기자, 다른 경기 선수)이 나오고 거기서 고름
- **권장안**: c) — 휴대폰 한 손 조작(UXD-001)에서는 드래그가 잘못 놓이기 쉽고, 탭-탭은 지금 무엇을 선택 중인지 알기 어렵습니다. 하단 시트는 참석·옵션 패널(UXD-002)과 같은 방식이라 익히기 쉽습니다. 확정 후에는 교체 버튼을 숨깁니다(AC-037).
- **관련**: FLOW-004-S5, FR-021, US-021, AC-035, AC-037

## 청백전 개념 정정 요청(라운드 밖, 2026-11-09)

### 질문
#### R22-Q1: 명단 목록 행에 급수를 표시할지(UXD-020)
- **선택지**: a) 이름 옆에 급수를 작은 글자로 표시(예: '김민수 · 남 · C조 · 7점'). 급수 필터는 두지 않음 / b) 목록에는 표시하지 않고 편집 시트(UXD-022)에서만 보여 줌 / c) 표시하고 목록 위에 급수 필터 칩도 둠
- **권장안**: a) — 운영진이 점수를 매길 때 급수를 참고하므로(FR-004, C-21) 목록에서 함께 보이는 편이 빠릅니다. 랭크·전적·튜토리얼 현황은 기획대로 목록에 넣지 않습니다. 필터는 기획에 없어 추가하지 않습니다.
- **관련**: FR-004, US-005, FLOW-003-S1, AC-012, C-21
#### R22-Q2: 청백전 목록의 진행 상태와 최종 결과 표시(UXD-028·UXD-041 통합)
- **선택지**: a) 두 결정을 하나로 합침: 항목마다 방식 배지('팀전'/'개인전')와 상태 배지('대진 미확정'/'진행 중'/'종료'). 진행 중에는 기존 요약(팀전 '청 x : 백 y', 개인전 '경기 n · 참가 m명')과 미기록 경기 수, 종료되면 최종 결과(팀전 '청팀 승리'·'무승부', 개인전 '1위 이름(공동 포함)') / b) 상태 배지만 추가하고 최종 결과는 상세 화면(UXD-072)에서만 / c) 진행 중·종료를 목록에서 두 섹션으로 나눔
- **권장안**: a) — 기록이 남은 청백전과 끝난 청백전이 한눈에 구분되어 승패 기록 100%(GOAL-003)를 지키기 쉽습니다. r3에서 순위 기준이 정해져(C-16) 개인전 1위도 목록에 보일 수 있습니다. 두 목록 결정을 하나로 합쳐 같은 화면의 규칙이 흩어지지 않게 합니다.
- **관련**: FR-014, FR-023, US-014, FLOW-005-S1, FLOW-005-S8, AC-042, C-16
