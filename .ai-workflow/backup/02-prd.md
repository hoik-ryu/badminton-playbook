# PRD: badminton-playbook

## 1. 배경 (Background)

배드민턴 동호회에는 두 가지 문제가 있습니다.

- **로테이션 이해 부족**: 복식 로테이션을 잘 몰라서 경기 중에 헤매는 회원이 있습니다(PRB-001).
- **대진 운영의 어려움**: 운영진은 지금 ChatGPT로 대진을 짜지만, 오류가 나거나 같은 경기가 반복되는 일이 생깁니다(PRB-002). 실력, 성별, 게임 수, 중복 같은 조건을 동시에 맞추기도 어렵습니다(PRB-003). 청백전 결과를 기록하고 이를 랭크로 연결할 수단도 없습니다(PRB-004).

badminton-playbook은 이 문제를 다음과 같이 해결합니다.

- 회원(PER-001)에게는 로테이션 학습을 제공합니다.
- 운영진(PER-002)과 슈퍼 관리자(PER-003)에게는 정확한 알고리즘으로 실시간 대진을 만들어 주고, 청백전 결과를 랭크로 관리하게 해 줍니다.

기준 문서: `01-discovery.md` r2(승인됨).

## 2. 목표와 비목표 (Goals / Non-Goals)

### 목표

- **GOAL-001**: 운영진이 ChatGPT 대신 이 서비스로 정확한 대진을 짭니다. 런칭 후 1개월 동안 정기 운동 대진을 100% 서비스로 생성하고, 같은 날 중복 경기는 0건이어야 합니다.
- **GOAL-002**: 회원이 복식 로테이션을 이해합니다. 지표와 목표치는 Q-013에서 정합니다.
- **GOAL-003**: 청백전 결과가 회원 랭크로 관리됩니다. 지표와 목표치는 Q-013에서 정합니다.

### 비목표

- 회원이 직접 참석을 등록하거나 알림을 받는 기능은 만들지 않습니다.
- 여러 동호회를 하나의 서비스에서 운영하는 기능은 만들지 않습니다.
- AI(LLM)로 대진을 생성하거나 추천하지 않습니다.
- 학습 효과를 측정하기 위한 학습 진도와 퀴즈 결과는 저장하지 않습니다.

## 3. 사용자 (Users)

| 사용자 | 사용 범위 | 사용하는 화면 |
|---|---|---|
| PER-001 회원 | 로테이션 학습, 마이페이지 | 모바일 전용 화면 |
| PER-002 운영진 | 회원·게스트·점수 관리, 실시간 대진, 청백전 | PC·모바일 반응형 화면 |
| PER-003 슈퍼 관리자 | 운영진 기능 전체 + 운영진 지정·해제 | PC·모바일 반응형 화면 |
| PER-004 게스트 | 로그인하지 않음. 운영진이 대진에 포함시킴 | 없음 |

운영진과 슈퍼 관리자도 회원 기능(학습, 마이페이지)을 쓸 수 있다고 가정합니다(ASM-020).

## 4. 기능 요구사항 (Functional Requirements)

| ID | 요구사항 | 우선순위 (Must/Should/Could) | 추적 대상 |
|---|---|---|---|
| FR-001 | **회원 가입과 로그인**: 회원 가입(이름, 성별, 로그인 정보)과 로그인, 로그아웃을 지원합니다. 로그인 방식은 Q-014에서 정합니다. | Must | PRB-001, PER-001, GOAL-002 |
| FR-002 | **가입 승인**: 가입 신청은 '승인 대기' 상태가 되고, 운영진이 승인하거나 거절합니다. 승인 전에는 학습과 마이페이지 등 회원 기능을 쓸 수 없습니다. | Must | PER-001, PER-002 |
| FR-003 | **역할과 권한**: 역할은 회원(member), 운영진(admin), 슈퍼 관리자(super_admin) 세 가지입니다. 운영진 지정과 해제는 슈퍼 관리자만 할 수 있고, 그 밖의 운영 기능은 운영진과 슈퍼 관리자가 똑같이 씁니다. 운영 기능은 운영진 이상만 접근할 수 있습니다. | Must | GOAL-001, PER-002, PER-003 |
| FR-004 | **회원 명단 관리**: 운영진은 회원 명단을 조회하고, 회원을 직접 추가(이름, 성별, 점수)하거나 정보를 수정할 수 있습니다. | Must | PRB-003, PER-002, GOAL-001 |
| FR-005 | **게스트 관리**: 운영진은 게스트를 이름, 성별, 점수로 만들고 언제든 삭제할 수 있습니다. 게스트는 로그인하지 않고 랭크 대상도 아닙니다. | Must | PRB-003, PER-004, GOAL-001 |
| FR-006 | **회원 점수**: 운영진은 회원과 게스트에게 1–10 사이의 정수 점수를 매기고 수정할 수 있습니다. 점수는 운영진 이상에게만 보이며, 청백전 결과로 자동으로 바뀌지 않습니다. | Must | PRB-003, PER-002, GOAL-001 |
| FR-007 | **운동 세션과 참석 체크**: 운영진이 그날의 운동 세션을 열고 회원 명단과 게스트 중에서 참석자를 체크합니다. 라운드 사이에 참석자를 추가하거나 뺄 수 있습니다. | Must | PRB-002, PRB-003, PER-002, GOAL-001 |
| FR-008 | **대진 옵션**: 운영진이 생성 방식(레벨별 또는 무작위)을 하나 고르고, 규칙 4가지(밸런스, 성별 조합, 게임 수 공평성, 파트너·상대 중복 회피)를 하나씩 켜거나 끕니다. 규칙은 여러 개를 함께 켤 수 있습니다. 규칙별 정의는 ASM-007–011을 따릅니다. | Must | PRB-003, PER-002, GOAL-001 |
| FR-009 | **라운드 대진 생성**: 참석자와 옵션을 바탕으로 한 라운드의 경기를 코트 수(ASM-013)만큼 한 번에 생성합니다. 출전 가능한 인원이 모자라면 4명 단위로 채울 수 있는 코트만큼만 경기를 만들고, 나머지 인원은 대기자로 표시합니다. 직전 라운드의 대기자는 다음 라운드에 우선 배정합니다. | Must | PRB-002, PRB-003, GOAL-001 |
| FR-010 | **결정적 알고리즘과 규칙 완화**: AI 없이 결정적 알고리즘으로 대진을 생성합니다. 같은 입력과 시드(ASM-012)에서는 항상 같은 결과가 나옵니다. 켜진 규칙을 모두 만족할 수 없으면 게임 수 공평성 > 중복 회피 > 성별 조합 > 밸런스 순으로, 우선순위가 낮은 규칙부터 완화합니다. 공평성과 중복 회피는 같은 날 세션 안의 기록으로 판단합니다. | Must | PRB-002, PRB-003, GOAL-001 |
| FR-011 | **대진 수정과 확정**: 확정 전에 운영진이 경기 안의 선수를 대기자나 다른 경기 선수와 맞바꾸거나, 라운드 전체를 다시 생성할 수 있습니다. 확정하면 그 라운드가 '진행 중'이 됩니다. | Must | PRB-002, PER-002, GOAL-001 |
| FR-012 | **라운드 완료와 이력 누적**: 운영진이 진행 중인 라운드를 완료하면, 확정된 경기 내용(파트너, 상대, 게임 수, 대기 여부)이 세션 이력에 쌓이고 다음 라운드 생성에 쓰입니다. 한 세션에서 라운드를 여러 번 진행할 수 있습니다. | Must | PRB-002, PRB-003, GOAL-001 |
| FR-013 | **규칙 완화 표시**: 생성된 대진에서 완화된 규칙이 있으면, 어떤 규칙이 어느 경기에서 완화됐는지 운영진에게 보여 줍니다. | Should | PRB-003, PER-002, GOAL-001 |
| FR-014 | **청백전 생성과 팀 편성**: 운영진이 일반 운동과 분리된 청백전 메뉴에서 청백전을 만들고, 참가자를 청팀과 백팀으로 직접 나눕니다. | Must | PRB-004, PER-002, GOAL-003 |
| FR-015 | **청백전 경기 편성과 승패 기록**: 운영진이 청팀 2명 대 백팀 2명으로 경기를 편성하고, 경기마다 이긴 팀을 기록하거나 수정합니다. 게임 스코어는 기록하지 않습니다. | Must | PRB-004, PER-002, GOAL-003 |
| FR-016 | **랭크 산정**: 회원의 청백전 경기별 승패 기록으로 승률을 계산합니다. 최소 경기 수를 채운 회원에게만 승률 구간별 등급을 매기고, 기준에 못 미치는 회원은 '랭크 없음'으로 표시합니다. 구간과 최소 경기 수는 ASM-014, 산정 기간은 Q-017을 따릅니다. 게스트는 제외합니다. 승패 기록이 바뀌면 랭크도 다시 계산합니다. | Must | PRB-004, GOAL-003 |
| FR-017 | **로테이션 학습 콘텐츠**: 로그인한 승인 회원이 공격 대형(Top & Back), 수비 대형(Side by Side), 공격↔수비 전환, 서브·리시브 위치 4개 주제를 코트 다이어그램과 애니메이션으로 볼 수 있습니다. 콘텐츠는 미리 만든 고정 콘텐츠입니다. | Must | PRB-001, PER-001, GOAL-002 |
| FR-018 | **상황 퀴즈**: 각 학습 주제에 상황 퀴즈("이때 어디로 가야 할까?")를 제공합니다. 답을 고르면 바로 정답 여부와 해설을 보여 줍니다. 퀴즈 결과는 저장하지 않습니다. | Must | PRB-001, PER-001, GOAL-002 |
| FR-019 | **마이페이지**: 회원이 자기 프로필(이름, 성별 등)을 보고 수정할 수 있고, 본인 랭크와 청백전 전적(경기 수, 승, 패, 승률)을 볼 수 있습니다. 1–10 점수는 보이지 않습니다. | Must | PRB-004, PER-001, GOAL-003 |

## 6. 범위 제외 (Out of Scope)

- 회원용 앱과 알림
- 코트 예약, 회비 결제
- 여러 동호회 지원(단일 동호회 기준)
- 영상 콘텐츠
- 일반 운동 게임의 결과·승패 기록
- 학습 진도·퀴즈 결과 저장
- 학습 콘텐츠 편집 기능(다음 버전)
- 전체 랭킹 보드
- 청백전 게임 스코어(예: 21-17) 기록
- 경기 결과에 따른 1–10 점수 자동 조정
- 회원이 자기 점수를 보는 기능

## 9. 릴리스 기준 (Release Criteria)

다음 조건을 모두 만족하면 MVP가 완료된 것으로 봅니다.

1. Must FR(FR-001–012, FR-014–019)에 연결된 AC가 `05-acceptance-criteria.md`에서 모두 통과합니다.
2. 참석 20명, 코트 4면 조건에서 라운드를 연속 5번 생성했을 때 같은 날 같은 경기가 0건이고(NFR-003), 매번 2초 이내에 생성됩니다(NFR-004).
3. 회원 권한으로는 어떤 화면과 API에서도 1–10 점수가 노출되지 않습니다(NFR-005).
4. Must FR에 영향을 주는 Q-014–017이 해결되었거나, 사용자가 제안 기본값을 받아들였습니다.
5. 학습 콘텐츠 4개 주제와 각 주제의 퀴즈가 준비되었고 검수를 마쳤습니다(Q-012).
