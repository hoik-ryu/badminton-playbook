## 한계(원본 벡터 필요)

- 보드가 래스터라 가장자리는 원본 픽셀 해상도(메인 로고 폭 약 860px)를 넘지 못합니다. 로그인 표시 폭 280px 기준 약 4배라 웹에는 충분하지만, 인쇄·대형 배너·스토어 그래픽에는 **원본 벡터(SVG/AI)** 가 필요합니다.
- 밝은 배경용은 어두운 배경 로고의 모양을 재채색한 것이라, 디자이너 원본의 밝은 배경용 색·그라데이션과 다를 수 있습니다.
- 속도 궤적 왼쪽 끝은 보드에서 빛 번짐으로 흐려지는 부분이라 단색 마스크에서 끝이 약간 거칩니다.
- 16px 파비콘은 깃 3개가 뭉쳐 '오른쪽 위로 기운 청록 부채꼴' 정도로만 읽힙니다(32·48px은 깃과 궤적 식별 가능). 작은 크기 전용 단순화 심볼은 디자이너 결정 사항입니다.
