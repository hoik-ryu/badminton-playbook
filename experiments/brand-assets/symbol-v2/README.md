## 방법
- 알파: 배경(어두운 픽셀로 맞춘 2차 곡면)보다 밝아진 정도 a를 계산해 a 0.50–0.64 구간을 모양 경계로 사용(빛 번짐 a≈0.2–0.45 제외). 2px 이하 티끌 4개 제거.
- 색(가장자리): F = (C − (1−m)·B) / m 로 배경을 걷어 낸 원래 색 → 검은·흰 테두리 없음.
- 여백: 긴 변의 6%(31px).

## 검증(실측)
- 두 파일 모두 PNG RGBA(색 형식 6), 573×322. 알파 채널 픽셀 단위 차이 0 → 윤곽·크기 동일.
- 알파 0 픽셀 81.4%, 가장자리 1px 띠의 최대 알파 0(배경 완전 투명). 반투명 픽셀 1,920개는 모양 가장자리 안티앨리어싱.

## 한계(보고)
- **왼쪽 아래 곡선형 스피드 라인**: 원본에서 이 부분은 윤곽이 있는 획이 아니라 부드러운 네온 빛으로 그려져 있어, 빛 번짐을 걷어 내면 가장자리가 거친 조각 모양이 됩니다. 원본 곡선을 그대로 살리려면 디자이너 원본(벡터·투명 PNG)이 필요합니다. 새로 그리지 않았습니다.
- 해상도: 심볼 본체 511×260px가 원본 한계입니다(확대·디테일 생성 안 함).
- 32px에서는 깃 3개가 보이지만 스피드 라인은 거의 사라집니다. 64px은 깃·코르크·라인 식별 가능.
