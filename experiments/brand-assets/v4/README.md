## 재생성

```sh
node experiments/brand-assets/v4/gen.mjs     # src/*.svg 생성 (기하 수치는 이 파일에 있음)
node experiments/brand-assets/v4/render.mjs  # out/, compare/ PNG 렌더 + 알파 검사(out/alpha-check.json)
```

렌더는 `experiments/c-preview-poc/`의 Playwright/Chromium을 읽기 전용으로 사용합니다. 로그인 목업의 `SMAPSH` 글자는 이미지가 아닌
실제 HTML 텍스트(Pretendard Variable, 800, 32px, `#006D68`)이며 폰트는 `frontend/node_modules/pretendard`에서 로컬로 불러옵니다.

## A · Smash Arc (스매시 아크) — 모션 추상

- **의도**: 높은 타점에서 휘어 내리꽂히는 스매시 궤적이 셔틀(원)을 밀어내는 '순간'. 셔틀콕을 그리지 않고 속도·방향만 추상화.
- **구성**: 큐빅 베지어 척추 1개를 따라 굵기가 8 → 38로 커지는 테이퍼 획(양끝 둥근 마감) + 반지름 18 원.
  획 끝은 원 중심에서 끝나고, 원 둘레를 따라 폭 4.5의 일정한 간격을 마스크로 비워 꼬리가 셔틀을 '감싸며 밀어내는' 형태.
  (처음 시안처럼 획과 점을 떨어뜨리면 `?`/`!` 같은 구두점으로 읽혀서 이 방식으로 바꿈)
- **색**: 꼬리 민트 → `#008F89` → `#006D68` 선형 그라디언트, 원은 `#006D68`. 모노/화이트는 단색.
- **장점**: 가장 역동적이고 '스매시'라는 이름과 직접 연결. 구성 요소 2개로 단순.
- **단점**: 대각선 구도라 우상·좌하 여백이 커서 정사각 프레임 안에서 덩어리감이 가장 약함. 혜성/유성처럼 범용적으로 읽힐 수 있어 배드민턴 고유성은 B보다 약함.
- **작은 크기**: 32px에서 원 주변 간격(약 1.2px)은 흐려지지만 '꼬리 + 원' 실루엣은 유지. 64px부터 간격이 또렷함.

## B · Geo Shuttle (지오 셔틀) — 배드민턴 요소의 기하 단순화

- **의도**: 셔틀콕을 원(코르크) + 부채꼴 날개 3장으로만 환원. 40° 기울여 코르크가 앞장서 날아가는 비행 자세로 역동성 부여.
- **구성**: 가상의 꼭짓점을 중심으로 한 부채꼴(반각 20°, 반지름 50~94)을 일정 폭 4.5의 방사형 슬릿 2개로 3장 분할,
  각 날개는 동색 4px stroke(round join)로 모서리를 둥글림. 코르크는 반지름 16 원, 스커트와 간격을 둠.
- **색**: 날개 `#008F89` → `#006D68` 그라디언트, 코르크 민트 `#2BBFAF`(포인트). 모노/화이트는 단색.
- **장점**: 한눈에 '배드민턴'으로 읽혀 앱 아이콘·파비콘에서 정체성이 가장 분명. 무게중심이 안정적이고 둥근 모서리가 앱 UI(radius 10px, Lucide)와 잘 어울림.
- **단점**: 셔틀콕 아이콘 자체는 흔한 모티프라 차별성/독창성은 C보다 낮음. 민트 코르크는 흰 배경에서 대비가 다소 약함(모노 버전은 문제없음).
- **작은 크기**: 32px에서 슬릿은 약 1px로 흐려지지만 '원 + 부채꼴' 실루엣으로 셔틀콕 인식 가능. 64px부터 날개 3장이 명확.

## C · Rally S (랠리 S) — S 레터마크

- **의도**: SMAPSH의 **S**를 두 획으로 나눠 '주고받는 랠리'(위 획 → 아래 획으로 넘어가는 공)를 표현. 이탤릭 기울기로 속도감.
- **구성**: 타원호(rx 24, ry 21) 2개를 이어 만든 기하학적 S, 획 굵기 17.5·둥근 캡, `skewX(-10)`.
  척추를 32° 사선으로 폭 6만큼 끊되 획마다 국소 마스크를 따로 적용해 서로의 끝 캡이 침범하지 않게 함.
- **색**: 위 획 `#006D68`, 아래 획 `#008F89` → 민트 그라디언트(투톤으로 '두 번의 타구'를 강조). 모노/화이트는 단색이며 사선 컷으로 두 획 구분이 유지됨.
- **장점**: 브랜드명과 직접 연결되는 고유 자산. 굵은 획이라 32px에서도 가장 선명하고, 정사각 안에서 광학 중심이 정확히 50/50.
  둥근 캡이 앱의 친근한 컴포넌트 톤과 잘 맞음.
- **단점**: 배드민턴 맥락은 이름/설명이 있어야 전달됨(모티프 자체는 스포츠 일반). 'S' 레터마크는 다른 서비스와 겹칠 가능성이 상대적으로 큼.
- **작은 크기**: 32px에서도 S 형태가 가장 또렷함. 사선 컷은 32px에서 약 1.6px로 보임.

## 알파(투명) 검사

`render.mjs`가 캔버스 `getImageData`로 모든 투명 PNG의 네 모서리 알파를 확인합니다 → 전부 `0,0,0,0`.
불투명 영역 bbox 중심/무게중심도 함께 기록됩니다(`out/alpha-check.json`).

## 적용 시 참고

- A·C는 `<mask>`를 사용합니다. 한 HTML에 여러 개를 인라인할 경우 mask id 충돌을 피하려면 `<img>`로 쓰거나,
  디자인 툴에서 아웃라인(불리언 연산)해 단일 path로 정리하는 것을 권장합니다.
- 실제 적용 전 디자인 리뷰와 사람의 검토가 필요합니다.
