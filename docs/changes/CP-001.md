> 엔진이 생성한 문서입니다. 직접 수정하지 말고 amend-contract로 개정합니다.

## 목적
운영진이 잘못 만든 청백전이나 개최 전에 취소된 청백전을 삭제할 수 있게 한다(준비 중 + 진행 예정)

## 정책
삭제 가능: 준비 중(draft), 진행 예정(확정 + 날짜가 오늘(KST)보다 뒤 + 기록된 결과 없음). 삭제 불가: 진행 중·종료, 일반 회원(모든 상태). 진행 예정이라도 운영 이력(경기 결과, 경기 취소·이벤트 기록, 중도 귀가 제외자, 2라운드 이상 진행)이 있으면 차단. 확정 때 1라운드가 진행 중으로 설정되는 것만으로는 차단하지 않음. 권한·상태·이력은 서버가 행 잠금 + version으로 검사하고, 참가자·대진·경기 선수는 한 트랜잭션에서 지우며 회원·게스트·명단 점수 등 공통 데이터는 지우지 않음. 기존 삭제 API(DELETE /api/club-matches/{id}?version=)를 그대로 씀
