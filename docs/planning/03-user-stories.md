# 사용자 스토리 (User Stories): badminton-playbook

## 스토리 목록

### US-001: 회원 가입 신청

- **사용자(As a)**: PER-001 회원
- **원하는 것(I want)**: 카카오 로그인으로 들어와서 이름과 성별을 입력하고 가입 신청하기
- **기대 효과(So that)**: 운영진의 승인을 받아 동호회 회원으로 서비스를 쓸 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-001, FR-002, PER-001
- **비고**: 카카오 로그인은 Q-014 답변으로 확정했습니다. 직접 입력은 ASM-022를 따릅니다.

### US-002: 로그인과 로그아웃

- **사용자(As a)**: PER-001 회원, PER-002 운영진, PER-003 슈퍼 관리자
- **원하는 것(I want)**: 카카오 계정으로 로그인하고 로그아웃하기
- **기대 효과(So that)**: 역할에 맞는 기능을 쓸 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-001, FR-003, PER-001, PER-002, PER-003

### US-003: 가입 승인과 거절

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 승인 대기 중인 가입 신청을 보고 승인하거나 거절하기
- **기대 효과(So that)**: 동호회 사람만 회원 명단에 들어옵니다
- **우선순위**: Must
- **추적 대상**: FR-002, FR-004, PER-002

### US-004: 운영진 지정과 해제

- **사용자(As a)**: PER-003 슈퍼 관리자
- **원하는 것(I want)**: 회원을 운영진으로 지정하거나 운영진에서 해제하기
- **기대 효과(So that)**: 운영을 여러 운영진이 함께 나눠 맡을 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-003, PER-003
- **비고**: 최초 슈퍼 관리자는 ASM-015를 따릅니다.

### US-005: 회원 명단 관리

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 회원 명단을 보고, 회원을 직접 추가하거나 회원의 이름과 성별을 수정하기
- **기대 효과(So that)**: 가입하지 않은 기존 회원도 대진에 넣을 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-004, PER-002
- **비고**: 비활성 처리는 US-020에서 다룹니다.

### US-006: 게스트 등록과 삭제

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 그날 온 게스트를 이름, 성별, 점수로 등록하고 필요 없으면 삭제하기
- **기대 효과(So that)**: 게스트도 대진에 포함할 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-005, FR-006, PER-002, PER-004
- **비고**: ASM-019

### US-007: 회원 점수 책정

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 회원과 게스트에게 1–10 점수를 매기고 수정하기. 이 점수는 운영진만 볼 수 있어야 합니다
- **기대 효과(So that)**: 레벨별 대진과 밸런스 대진이 실력을 반영합니다
- **우선순위**: Must
- **추적 대상**: FR-006, PER-002

### US-008: 운동 세션 열기와 참석 체크

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 그날의 운동 세션을 열고, 참석자를 체크하고, 라운드 사이에 늦게 온 사람을 추가하거나 먼저 간 사람을 빼기
- **기대 효과(So that)**: 실제로 현장에 있는 사람만으로 대진을 짤 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-007, PER-002
- **비고**: ASM-016

### US-009: 대진 옵션 선택

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 생성 방식(레벨별 또는 무작위)을 고르고, 규칙 4가지를 하나만 켜거나 여러 개 함께 켜기
- **기대 효과(So that)**: 그날 분위기와 목적에 맞는 대진을 짤 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-008, PER-002
- **비고**: 규칙 정의는 PRD 7.1의 확정 사항 C-01–C-05를 따릅니다.

### US-010: 라운드 대진 자동 생성

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 버튼 한 번으로 코트 4면에 들어갈 경기를 한 번에 생성하기
- **기대 효과(So that)**: ChatGPT 없이도 오류 없고 반복되지 않는 대진을 바로 얻을 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-009, FR-010, PER-002
- **비고**: 확정 사항 C-04, C-06

### US-011: 대진 재생성과 확정

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 생성된 대진이 마음에 들지 않으면 다시 생성하고, 괜찮으면 확정하기
- **기대 효과(So that)**: 현장 상황에 맞는 대진으로 라운드를 시작할 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-011, PER-002
- **비고**: r2에서 범위를 줄였습니다. 선수 수동 교체는 US-021(Should)로 옮겼습니다. 동시 조작 충돌은 확정 사항 C-10을 따릅니다.

### US-012: 라운드 완료와 다음 라운드 진행

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 라운드의 4경기가 모두 끝나면 라운드를 완료 처리하고 다음 라운드를 생성하기
- **기대 효과(So that)**: 그날의 게임 수와 파트너 기록이 다음 대진에 반영됩니다
- **우선순위**: Must
- **추적 대상**: FR-012, FR-009, PER-002

### US-013: 완화된 규칙 확인

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 생성된 대진에서 어떤 규칙이 지켜지지 않았는지 보기
- **기대 효과(So that)**: 대진 결과를 이해하고, 필요하면 직접 고칠 수 있습니다
- **우선순위**: Should
- **추적 대상**: FR-013, PER-002

### US-014: 청백전 만들기와 팀 편성

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 청백전 메뉴에서 청백전을 만들고 참가자를 청팀과 백팀으로 나누기
- **기대 효과(So that)**: 자체 대회를 일반 운동과 따로 운영할 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-014, PER-002
- **비고**: 게스트도 참가할 수 있습니다(확정 사항 C-09).

### US-015: 청백전 경기 편성과 승패 기록

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 청팀 2명 대 백팀 2명으로 경기를 편성하고, 경기마다 이긴 팀을 기록하거나 수정하기
- **기대 효과(So that)**: 청백전 결과가 회원 랭크의 근거가 됩니다
- **우선순위**: Must
- **추적 대상**: FR-015, PER-002

### US-016: 청백전 기록으로 랭크 산정

- **사용자(As a)**: PER-001 회원
- **원하는 것(I want)**: 청백전 승패 기록에 따라 내 랭크가 자동으로 정해지기
- **기대 효과(So that)**: 내 실력이 공정한 기준으로 평가받습니다
- **우선순위**: Must
- **추적 대상**: FR-016, PER-001
- **비고**: 확정 사항 C-07, C-09

### US-017: 로테이션 학습 콘텐츠 보기

- **사용자(As a)**: PER-001 회원
- **원하는 것(I want)**: 공격 대형, 수비 대형, 전환, 서브·리시브 위치를 코트 다이어그램과 애니메이션으로 보기
- **기대 효과(So that)**: 복식에서 어디에 서고 언제 움직여야 하는지 이해할 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-017, PER-001
- **비고**: 콘텐츠는 기획자가 초안을 만들고 운영진이 검수합니다(Q-012 해결).

### US-018: 상황 퀴즈 풀기

- **사용자(As a)**: PER-001 회원
- **원하는 것(I want)**: 각 주제의 상황 퀴즈를 풀고 바로 정답과 해설을 보기
- **기대 효과(So that)**: 배운 내용을 실제 상황에 적용해 볼 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-018, PER-001

### US-019: 마이페이지

- **사용자(As a)**: PER-001 회원
- **원하는 것(I want)**: 내 프로필을 보고 수정하고, 내 랭크와 청백전 전적을 보기
- **기대 효과(So that)**: 내 정보와 청백전 성과를 확인할 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-019, PER-001

### US-020: 회원 비활성 처리 *(r2 신규)*

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 활동을 멈춘 회원을 비활성으로 바꾸고, 돌아오면 다시 활성화하기
- **기대 효과(So that)**: 참석 체크 목록에 지금 활동하는 회원만 보입니다
- **우선순위**: Should
- **추적 대상**: FR-020, PER-002

### US-021: 대진 선수 수동 교체 *(r2 신규, US-011에서 분리)*

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 확정 전에 경기에 배정된 선수를 대기자나 다른 경기 선수와 맞바꾸기
- **기대 효과(So that)**: 부상이나 잠깐 자리를 비운 사람 같은 현장 사정을 반영할 수 있습니다
- **우선순위**: Should
- **추적 대상**: FR-021, PER-002
