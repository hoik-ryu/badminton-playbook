# 사용자 스토리 (User Stories): badminton-playbook

> **r3 개정**: PF-001~006 반영. 수정한 스토리는 비고에 (r3)으로 표시했고, 폐기한 스토리는 취소선으로 남겼습니다. 신규 스토리는 US-022부터입니다.

> **r4 개정**: 스토리 내용은 바뀌지 않았습니다. Planning 문서 4개가 revision을 함께 쓰므로 front matter revision만 4로 올렸습니다. r4에서 추가한 세션 규칙(C-25)과 게스트 삭제 제한(C-26)은 US-008·US-006의 AC(AC-101–AC-106)로 확인합니다.

> **r5 개정**: 새 스토리를 추가하거나 폐기하지 않았습니다. I3에서 확정한 청백전 운영 정책(C-15·C-19·C-20 보강)을 US-015·US-023의 비고에 연결했고, AC-108–AC-110으로 확인합니다. Planning 문서 4개가 revision을 함께 쓰므로 front matter revision을 5로 올렸습니다.

## 스토리 목록

### US-001: 회원 가입 신청

- **사용자(As a)**: PER-001 회원
- **원하는 것(I want)**: 카카오 로그인으로 들어와서 이름, 성별, 급수, (선택) 누구의 지인인지를 입력하고 가입 신청하기
- **기대 효과(So that)**: 운영진의 승인을 받아 동호회 회원으로 서비스를 쓸 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-001, FR-002, PER-001
- **비고**: 카카오 로그인은 Q-014 답변으로 확정했습니다. 직접 입력은 ASM-022를 따릅니다. (r3) 급수는 필수, 지인 정보는 선택입니다(C-21).

### US-002: 로그인과 로그아웃

- **사용자(As a)**: PER-001 회원, PER-002 운영진, PER-003 슈퍼 관리자
- **원하는 것(I want)**: 카카오 계정으로 로그인하고 로그아웃하기
- **기대 효과(So that)**: 역할에 맞는 기능을 쓸 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-001, FR-003, PER-001, PER-002, PER-003

### US-003: 가입 승인과 거절

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 승인 대기 중인 가입 신청을 (r3) 급수·지인 정보와 함께 보고 승인하거나 거절하기
- **기대 효과(So that)**: 동호회 사람만 회원 명단에 들어옵니다
- **우선순위**: Must
- **추적 대상**: FR-002, FR-004, PER-002

### US-004: 운영진 지정과 해제

- **사용자(As a)**: PER-003 슈퍼 관리자
- **원하는 것(I want)**: 회원을 운영진으로 지정하거나 운영진에서 해제하기
- **기대 효과(So that)**: 운영을 여러 운영진이 함께 나눠 맡을 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-003, PER-003
- **비고**: 최초 슈퍼 관리자는 ASM-015를 따릅니다.

### US-005: 회원 명단 관리

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 회원 명단을 보고, 회원을 직접 추가하거나 회원의 이름, 성별, (r3) 급수를 수정하고, 회원 편집 화면에서 지인 정보·랭크·누적 청백전 전적·튜토리얼 통과 현황을 확인하기
- **기대 효과(So that)**: 가입하지 않은 기존 회원도 대진에 넣을 수 있고, 회원을 관리할 때 필요한 정보를 한곳에서 봅니다
- **우선순위**: Must
- **추적 대상**: FR-004, PER-002
- **비고**: 비활성 처리는 US-020에서 다룹니다. (r3) 직접 추가할 때 급수는 필수입니다(C-21). 랭크·전적 표시는 PF-004 결정입니다.

### US-006: 게스트 등록과 삭제

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 그날 온 게스트를 이름, 성별, (r3) 급수, 점수로 등록하고 필요 없으면 삭제하기
- **기대 효과(So that)**: 게스트도 대진과 청백전에 포함할 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-005, FR-006, PER-002, PER-004
- **비고**: ASM-019. (r3) 게스트 급수는 필수이며 운영진이 고릅니다(C-21).

### US-007: 회원 점수 책정

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 회원과 게스트에게 1–10 점수를 매기고 수정하기. 이 점수는 운영진만 볼 수 있어야 합니다
- **기대 효과(So that)**: 레벨별 대진과 밸런스 대진이 실력을 반영합니다
- **우선순위**: Must
- **추적 대상**: FR-006, PER-002

### US-008: 운동 세션 열기와 참석 체크

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 그날의 운동 세션을 열고, 참석자를 체크하고, 라운드 사이에 늦게 온 사람을 추가하거나 먼저 간 사람을 빼기
- **기대 효과(So that)**: 실제로 현장에 있는 사람만으로 대진을 짤 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-007, PER-002
- **비고**: ASM-016

### US-009: 대진 옵션 선택

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 생성 방식(레벨별 또는 무작위)을 고르고, 규칙 4가지를 하나만 켜거나 여러 개 함께 켜기
- **기대 효과(So that)**: 그날 분위기와 목적에 맞는 대진을 짤 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-008, PER-002
- **비고**: 규칙 정의는 PRD 7.1의 확정 사항 C-01–C-05를 따릅니다.

### US-010: 라운드 대진 자동 생성

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 버튼 한 번으로 코트 4면에 들어갈 경기를 한 번에 생성하기
- **기대 효과(So that)**: ChatGPT 없이도 오류 없고 반복되지 않는 대진을 바로 얻을 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-009, FR-010, PER-002
- **비고**: 확정 사항 C-04, C-06

### US-011: 대진 재생성과 확정

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 생성된 대진이 마음에 들지 않으면 다시 생성하고, 괜찮으면 확정하기
- **기대 효과(So that)**: 현장 상황에 맞는 대진으로 라운드를 시작할 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-011, PER-002
- **비고**: r2에서 범위를 줄였습니다. 선수 수동 교체는 US-021(Should)로 옮겼습니다. 동시 조작 충돌은 확정 사항 C-10을 따릅니다.

### US-012: 라운드 완료와 다음 라운드 진행

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 라운드의 4경기가 모두 끝나면 라운드를 완료 처리하고 다음 라운드를 생성하기
- **기대 효과(So that)**: 그날의 게임 수와 파트너 기록이 다음 대진에 반영됩니다
- **우선순위**: Must
- **추적 대상**: FR-012, FR-009, PER-002

### US-013: 완화된 규칙 확인

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 생성된 대진에서 어떤 규칙이 지켜지지 않았는지 보기
- **기대 효과(So that)**: 대진 결과를 이해하고, 필요하면 직접 고칠 수 있습니다
- **우선순위**: Should
- **추적 대상**: FR-013, PER-002

### US-014: 청백전 만들기, 방식 선택, 참가자 선정 *(r3 재작성)*

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 청백전을 만들면서 개인전 또는 팀전을 고르고, 참가 선수(게스트 포함)를 선정하고, 팀전이면 알고리즘이 제안한 청·백 배정을 조정하기
- **기대 효과(So that)**: 회원이 따로 신청하지 않아도 운영진이 자체 대회를 일반 운동과 따로 준비할 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-014, PER-002
- **비고**: (r3) C-13, C-19. 방식은 확정 전까지 바꿀 수 있습니다. 게스트 참가는 C-09.

### US-015: 청백전 대진 생성·확정과 결과 기록 *(r3 재작성)*

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 총 경기 수를 정해 전체 대진을 한 번에 생성하고, 검토·보정한 뒤 확정하고, 확정 후에는 경기마다 이긴 쪽을 기록하고, 먼저 간 선수의 남은 경기에 대체 선수를 정하고, 모든 결과가 기록되면 청백전을 종료하기
- **기대 효과(So that)**: 공정한 대진으로 청백전을 운영하고 결과가 순위와 회원 랭크의 근거가 됩니다
- **우선순위**: Must
- **추적 대상**: FR-015, FR-023, PER-002
- **비고**: (r3) C-14, C-15, C-16, C-19, C-20. (r5) 중도 귀가 대체의 같은 대진 예외(C-19, AC-108)와 진행 중 결과 되돌리기(C-20, AC-109)

### US-016: 청백전 기록으로 랭크 산정

- **사용자(As a)**: PER-001 회원
- **원하는 것(I want)**: 청백전 승패 기록에 따라 내 랭크가 자동으로 정해지기
- **기대 효과(So that)**: 내 실력이 공정한 기준으로 평가받습니다
- **우선순위**: Must
- **추적 대상**: FR-016, PER-001
- **비고**: 확정 사항 C-07, C-09. (r3) 개인전·팀전 모든 경기를 반영하고, 대체 선수 경기는 실제로 뛴 사람의 기록입니다(C-15, C-17).

### US-019: 마이페이지

- **사용자(As a)**: PER-001 회원
- **원하는 것(I want)**: 내 프로필(이름, 성별, (r3) 급수)을 보고 수정하고, 내 랭크와 청백전 전적을 보기
- **기대 효과(So that)**: 내 정보와 청백전 성과를 확인할 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-019, PER-001

### US-020: 회원 비활성 처리 *(r2 신규)*

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 활동을 멈춘 회원을 비활성으로 바꾸고, 돌아오면 다시 활성화하기
- **기대 효과(So that)**: 참석 체크 목록에 지금 활동하는 회원만 보입니다
- **우선순위**: Should
- **추적 대상**: FR-020, PER-002

### US-021: 대진 선수 수동 교체 *(r2 신규, US-011에서 분리)*

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 확정 전에 경기에 배정된 선수를 대기자나 다른 경기 선수와 맞바꾸기
- **기대 효과(So that)**: 부상이나 잠깐 자리를 비운 사람 같은 현장 사정을 반영할 수 있습니다
- **우선순위**: Should
- **추적 대상**: FR-021, PER-002

### US-022: 대진 실력차 확인 *(r3 신규)*

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 일반 게임과 청백전 대진을 만들고 고칠 때 경기마다 두 팀의 실력 점수 차이('실력차 N점')를 보고, 선수를 바꾸기 전에 바꾼 뒤의 실력차를 미리 보기
- **기대 효과(So that)**: 한쪽으로 기운 경기를 쉽게 찾아 보정할 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-022, PER-002
- **비고**: C-24. 참고 정보이며 제한·경고는 없습니다. 회원에게는 보이지 않습니다.

### US-023: 확정된 청백전 조회 *(r3 신규)*

- **사용자(As a)**: PER-001 회원
- **원하는 것(I want)**: 확정된 청백전의 전체 대진, 결과, 순위나 팀 승수를 보고 내 경기를 바로 찾기
- **기대 효과(So that)**: 현장에서 내 차례와 파트너·상대를 미리 알고, 대회 결과를 확인할 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-024, FR-023, PER-001
- **비고**: C-18. 참가 신청 기능은 없습니다. (r5) 종료 후 결과 수정 안내는 대진 수정 안내와 구분됩니다(C-15, AC-110)

### US-024: 게임형 로테이션 튜토리얼 플레이 *(r3 신규, ~~US-017~~·~~US-018~~ 대체)*

- **사용자(As a)**: PER-001 회원
- **원하는 것(I want)**: 복식 경기 상황에서 내 움직임을 고르고, 선수와 셔틀콕이 움직이는 결과를 보며, 틀리면 이유를 보고 다시 도전하기
- **기대 효과(So that)**: 어디에 서고 언제 움직여야 하는지 직접 해 보며 익힐 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-025, PER-001
- **비고**: C-22. 튜토리얼 난이도는 회원 급수와 별개입니다.

### US-025: 튜토리얼 진행 확인 *(r3 신규)*

- **사용자(As a)**: PER-001 회원
- **원하는 것(I want)**: 어떤 스테이지를 통과했는지와 최고 점수, 난이도별 진행률을 보기
- **기대 효과(So that)**: 어디까지 익혔는지 알고 다음에 할 스테이지를 고를 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-026, PER-001

### US-026: 튜토리얼 권장 대상 관리 *(r3 신규)*

- **사용자(As a)**: PER-002 운영진
- **원하는 것(I want)**: 튜토리얼 권장 대상(1–10 점수 3 이하 또는 미설정) 중 아직 통과하지 않은 회원을 골라 보고 통과 현황을 확인하기
- **기대 효과(So that)**: 튜토리얼이 꼭 필요한 회원에게 현장에서 직접 권할 수 있습니다
- **우선순위**: Must
- **추적 대상**: FR-026, FR-004, PER-002
- **비고**: C-23. 회원 화면에는 개인별 추천을 두지 않습니다.
