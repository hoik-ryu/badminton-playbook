## 2. 화면 폭별 계산

가정: 기기 높이 360→800, 390→844, 430→932. 아래쪽 안전 영역은 iPhone 34px(390·430), Android 제스처 막대 0–24px(360). 안전 영역 값은 기기마다 다른 **가정**입니다.

| 항목 | 360×800 | 390×844 | 430×932 |
|---|---|---|---|
| 칩 줄 사용 폭(폭 − 좌우 32) | 328 → **두 줄로 줄바꿈**(컨트롤 +40) | 358 → 한 줄 | 398 → 한 줄 |
| 첫 화면에 보이는 행 수(헤더·컨트롤·탭 제외, 안전 영역 반영) | 약 7.1–7.6 | 약 8.5(안전 영역 없으면 9.1) | 약 10.0 |
| '게스트 추가' 왼쪽 끝 x | 206 | 236 | 276 |
| 행 글자 오른쪽 끝 최대(16 + 206) | 222 → **버튼과 16px 겹침**(서이든, 최라온 207) | 222 → 겹치지 않음(여유 14) | 222 → 겹치지 않음 |
| 5글자 이름(VD-007 자기 비평, 약 +32) | 겹침 확대 | 약 254 → **겹침** | 겹치지 않음 |
| 탭 1개 폭 | 90 | 98 | 108 |

- 행 수는 헤더와 컨트롤이 스크롤과 함께 올라가므로(고정 아님) 스크롤 후에는 더 늘어납니다.
- '겹침'은 행이 버튼 아래로 지나갈 때 점수·배지가 가려진다는 뜻입니다. 행 왼쪽은 그대로 누를 수 있습니다.
