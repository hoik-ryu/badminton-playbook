# 디자인 방향 (Design Direction): 배드민턴 플레이북 (badminton-playbook)

> **초안(2026-11-11)**. 정식 위치는 `docs/design/07-design-direction.md`입니다(v2 전환과 `begin --stage design_direction` 뒤 옮김). 아직 승인 대상이 아니며, VD·CR 결정은 사용자에게 받습니다.

승인된 UX 설계를 바꾸지 않고, 그 위에 어떤 모습으로 렌더링할지 정합니다. 여기서 승인된 시각 결정(VD)만 정식 렌더링(프리뷰)에 씁니다.
화면·정보·행동·토큰 이름을 바꿔야 하면 이 문서에서 결정하지 않고 7장 변경 요청(①·②)으로 남겨 UX 설계를 다시 엽니다.

## 1. 입력

- **UX 설계 기준**: ux_spec r1(승인됨), UX 결정 r2
- **디자인 프로필**: `docs/design-profile/`(stack.md, visual-decisions.md, token-mapping.md, component-mapping.md, figma.md)
- **브랜드·시각 방향**: C안 Mint Hybrid — 밝고 산뜻한 모바일 스포츠 클럽 앱. 테마 값은 `docs/design-profile/theme.json`(개발자 설정). 실험 기록: `docs/design-profile/reviews/C-mint-hybrid-full-design.md`, `SCR-211-code-first-poc.md`
- **컴포넌트·토큰 매핑**: `docs/design-profile/component-mapping.md`(CMP ↔ shadcn/ui + Radix), `docs/design-profile/token-mapping.md`(04 토큰 → CSS 변수)
- **규칙 출처**: UI UX Pro Max v2.15.0 커밋 `4f2dbb6`(데이터만 참조, 설치 안 함, 권위 순서 최하위)

## 2. 디자인 방향과 스타일 원칙

- 체육관 현장에서 한 손으로 빨리 읽고 누르는 업무 화면: 정보 밀도는 높게, 카드·그라데이션·장식은 쓰지 않음
- 브랜드 색(청록)은 주 행동과 현재 위치 표시에만 씀. 상태 색(성공·경고·위험)과 팀·코트 색은 04 의미 그대로
- 모든 누름 대상은 누름 영역 44 이상. 보이는 크기와 누름 영역을 따로 정함
- 글자 대비 4.5:1(큰 글자 3:1), 색만으로 구분하지 않음

## 3. 시각 결정 (VD)

### VD-001: 기본 글꼴 Pretendard
- **결정**: Pretendard Variable, 폴백 system-ui, sans-serif(테마 값 `font.family.base`)
- **상태**: 승인
- **근거**: 사용자 결정(2026-11-10). Code-first PoC에서 3개 폭 모두 적용 확인
- **관련**: font.family.base
- **토큰 밖 값**: 없음

### VD-002: 아이콘 세트 Lucide
- **결정**: lucide-react 아이콘만 씀
- **상태**: 승인
- **근거**: 사용자 결정(2026-11-10)
- **관련**: CMP-025, CMP-026
- **토큰 밖 값**: 없음

### VD-003: 웹 글꼴 로딩 방식
- **결정**: npm `pretendard` 패키지의 dynamic subset을 빌드에 포함(자체 호스팅)
- **상태**: 후보
- **근거**: PoC에서 외부 CDN 없이 동작. 인앱 브라우저 성능(서브셋 크기)은 미측정
- **관련**: font.family.base
- **토큰 밖 값**: 없음

### VD-004: 점수·인원 숫자는 고정폭 숫자
- **결정**: `tabular-nums`
- **상태**: 후보
- **근거**: 세로로 훑어볼 때 자릿수 정렬
- **관련**: CMP-024
- **토큰 밖 값**: 없음

### VD-007: 명단 행 구성
- **결정**: 이름(굵게) · 성별 · 급수 왼쪽, 점수는 오른쪽 열(굵게). 점수 없음은 '미설정' 배지
- **상태**: 후보
- **근거**: PoC 측정에서 넘침 0. 단, 표기 변경 여부는 CR-006 결정에 따름
- **관련**: CMP-024, CMP-005, UXD-074
- **토큰 밖 값**: 없음

### VD-008: 행 높이 56 + 구분선 1(행 안)
- **결정**: 행 전체 56(구분선 포함), 좌우 여백 16
- **상태**: 후보
- **근거**: PoC 측정 56 확인(1차에서 57 결함 수정)
- **관련**: CMP-024, color.border.default
- **토큰 밖 값**: 없음

### VD-010: 필터 칩 보이는 높이 32 · 누름 영역 44
- **결정**: 위아래 6px 누름 영역 확장, 두 줄일 때 줄 간격 12
- **상태**: 후보
- **근거**: PoC 측정. 줄 간격 8이면 누름 영역이 4px 겹침(360 밀도와의 균형은 4장)
- **관련**: CMP-004, color.border.strong
- **토큰 밖 값**: 있음(반경 16 — CR-010)

### VD-019: 하단 탭 Lucide 아이콘
- **결정**: 튜토리얼 graduation-cap, 청백전 swords, 마이페이지 circle-user-round, 운영 clipboard-list, 24px. 현재 탭은 아이콘 둘레 표시 + 굵은 글자 + 주 행동 색
- **상태**: 후보
- **근거**: 사용자 요청(C안). 아이콘 추가는 조건부 분류(CR-007)
- **관련**: CMP-025, color.action.primary
- **토큰 밖 값**: 있음(현재 탭 둘레 표시 색 — CR-003)

### VD-020: 하단 안전 영역
- **결정**: 하단 탭 아래 `env(safe-area-inset-bottom)`, 목록 끝 스크롤 여백 = 탭 높이 + 안전 영역 + 16, 포커스 스크롤 여백도 같게
- **상태**: 후보
- **근거**: PoC 측정에서 가림·포커스 가림 0(안전 영역 34 가정)
- **관련**: CMP-025, SCR-211
- **토큰 밖 값**: 없음
