# B4 청백전 운영 — 명세에 없어 임시로 정한 사항

- 작성: 2026-11-11 (B4 구현 중)
- 범위: SCR-221–226, `frontend/src/features/clubmatch/`
- 이 문서의 값은 **최종 정책이 아닙니다.** 기획 결정 시 바꾸고, 결정 기록 후 코드 반영합니다.

## 1. 정책 미정(임시 처리)

| ID | 항목 | 명세 상태 | 임시 처리 | 확인 포인트 |
|---|---|---|---|---|
| Q1 | 팀전 알고리즘 배정안 대상 | AC-072 '패널을 처음 열면 배정안을 채움'. 참가자가 아직 없을 때·일부만 팀이 있을 때 처리 없음 | 팀이 없는 참가자가 있을 때 패널을 처음 열면 **현재 참가자 전원**을 성별별 점수 지그재그로 다시 나눔(1회). 이후 사람을 추가하면 운영진이 직접 청·백을 고름 | 새로 추가한 사람 자동 배정 여부 |
| Q2 | 대진 생성 비용 순서 | C-15–C-18 각각 정의, 서로의 우선순위 없음 | 경기 수 차이 ≤1(필수) > 같은 4명·같은 팀 금지 > 파트너 반복 최소 > 성별 조합 > 밸런스 | 파트너 반복과 성별 충돌 시 결과 |
| Q3 | 확정 후 팀 변경 | 명세: 확정 후 같은 팀 안 교체만 | 팀 선택·참가 해제 잠금, 중도 귀가는 '이후 대진에서 제외' + 대체 선수(SCR-226)로만 | - |
| Q4 | 대체 선수 추천 기준 | AC-078 '대체 선수 지정', 추천 기준 없음 | 이 청백전 경기 수 적은 사람(같으면 이름순), 팀전은 같은 팀, 같은 경기 중복·같은 4명 같은 팀 구성은 비활성. 앞 경기 배정을 반영해 차례로 추천 | 추천 공평성 |
| Q5 | 교체 경고 기준 | C-14 '경기 수 차이 최대 1' | 교체 후 차이가 2 이상이면 확인 창으로 경고하고 운영진이 허용 가능(차단하지 않음) | 차단 여부 |
| Q6 | SCR-225 '경기 중' 표시 | 명세에 '경기 중' 언급, 청백전에는 '진행 중 경기' 개념이 없음(결과 기록 여부만 있음) | 표시하지 않음. 결과가 기록된 경기는 교체 불가 | 의미 확인 |
| Q7 | 종료 조건 | AC-085 | 미기록 경기가 있으면 '청백전 종료' 비활성 + 'n경기 남음'(누르면 첫 미기록 경기로 이동) | 강제 종료 필요 여부 |
