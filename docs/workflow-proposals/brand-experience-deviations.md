## 2. 인트로 정책(구현)

- 최초 방문에서 '/'로 들어올 때만 1회. 새로고침·재방문·직접 진입 링크·인증 콜백 착지 경로('/signup', '/account-status', '/tutorial', 원래 주소)는 생략.
- 건너뛰기 버튼·Esc, `prefers-reduced-motion`이면 재생 안 함, 이미지 2.5초 안에 준비 안 되면 생략(본 것으로 기록 안 함).
- 방문 기록: `localStorage` 'smapsh.introSeen.v1' = '1'(기기 안 표시, 개인 식별 정보 아님 → NFR-006과 충돌 없음). 저장소를 못 쓰면 재생하지 않음.
- 개발 빌드에서만 '/?intro=replay'로 다시 보기(`/dev` 화면에도 버튼).
- 코드: `frontend/src/features/intro/`(정책 `introPolicy.ts` + 테스트, 오버레이 `IntroOverlay.tsx`, 타임라인 `timeline.ts`).

## 3. 이미지 품질 문제(미해결)

- 인트로 경기 이미지 5장은 사용자 제공 6컷 시안에서 잘라낸 **저해상도 임시 자산**(장당 폭 364px). 화면에서 1.5–2.7배(고해상도 기기 3–5배) 확대되어 흐립니다. 확대로 해결했다고 보지 않습니다.
- 필요 자산: 컷마다 세로 1080×1920 이상, 사용 권한 확보, WebP·AVIF 장당 120KB 이하. 셔틀콕 클로즈업, 스매시, 선수 클로즈업, 복식 경기, 라켓 클로즈업(5장).
- 로고(v3)는 래스터 보드에서 추출해 원본 픽셀 해상도가 한계입니다(심볼 본체 500×255, 워드마크 846×97). 웹 표시는 충분하나 인쇄·대형 그래픽은 디자이너 원본(벡터)이 필요합니다.
