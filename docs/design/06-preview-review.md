### (r10) 회귀

- 바뀌지 않은 화면 56개 보기 + SCR-112 기존 6개 상태 + SCR-112-ST24(라운드 정보 없는 청백전, 승인본 ST13과 비교) + SCR-225-ST7(확정 후 교체, 라운드 없음) = 64건을 승인본(r9, HEAD 빌드)과 390×844 전체 페이지 캡처로 비교했습니다.
