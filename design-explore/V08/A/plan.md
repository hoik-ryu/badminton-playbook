# V08-A 디자인 계획(V07-A 수정 2회차)

## 시각 개념
- 사용자 피드백: V07-A는 기대한 방향과 다르고 초록이 지나치게 강함 → 새 배너 이미지 2장 기준으로 다시 제작.
- 글씨 있는 판(REF-003)은 글자 배치 기준으로만 쓰고, 서비스 배경은 글씨 없는 판(AST-079) 한 장. 대결 그래픽·월계수·셔틀콕은 이미지에 들어 있으므로 CSS·다른 이미지로 다시 만들지 않음.

## 색·토큰
- SMAPSH 공식 테마(docs/design-profile/theme.json)의 민트·틸로 통일. 후보 테마에서 바꾼 값 4개:
  - color.action.primary #25AB62 → #087F73(공식 focus.ring 값). 공식 primary #0B9E8B는 흰 글자 3.35:1이라 15px 버튼·12px 배지에는 못 씀. #087F73은 4.89:1.
  - color.text.accent #0B8655 → #10776C(공식 값). 흰 바탕 5.42:1, 연민트 배지 바탕 4.84:1.
  - color.hero.bg #065B55 → #026C6D(RX-003-11, 배너 이미지 위 가장자리 색). 흰 글자 6.3:1 이상.
  - color.hero.accent #9CCBFF → #5FFFFF(RX-003-08, '청팀' 시안).
- 적용: '새 청백전' 버튼·'진행 중' 배지·배너 배지 = action.primary, 섹션 아이콘·남은 경기 아이콘·하단 탭 활성 = text.accent, '진행 예정' 배지 = accent.subtle 바탕 + text.accent 글자, 진행 중 카드 테두리 = accent.mint.
- 청팀은 파랑(team.blue), 백팀은 흰색·중립(team.white, bg.surface) 그대로. 금색 #BA8200 그대로.
- 배너 배지: 레퍼런스 민트 #29B9A8은 흰 글자 2.44:1 → 틸 채움 + 민트 테두리(accent.mint 55%)로 민트 느낌 유지.

## 타이포그래피
- 데스크톱(배너 폭 560px 이상): REF-003 비율. 배지 2.4cqw, 제목 4.72cqw·행간 1.12, 설명 2.6cqw·행간 1.27(배너 574px에서 13.8·27.1·14.9px). 글꼴 차이(측정 환경에 Pretendard 없음 → 시스템 글꼴)를 겹침 비교로 보정.
- 모바일(배너 폭 560px 미만): 그대로 줄이면 제목 약 15px·설명 약 8px라 읽기 어려움 → 배지 11.5px, 제목 21px, 설명 13.5px(390px 기준, 폭에 비례). 설명은 그래픽과 겹치지 않도록 3줄로 다시 나눔(낱말 단위 줄바꿈).

## 간격·밀도
- 카드·섹션 간격은 V07-A 그대로(REF-002 RX-002-21).

## 컴포넌트 표현
- 배너: 이미지 상자 3:1 + contain(이미지와 상자 비율이 같아 왜곡·잘림 없음). 모바일은 이미지 위에 hero.bg 글자 띠(배너 폭의 18.4%)를 더하고 이미지 윗부분을 같은 색으로 자연스럽게 이음. 배너 높이 390px 188px, 360px 173px, 데스크톱 191px(=3:1).
- 이미지가 없으면 hero.bg 바탕 위 글자만 보임(장식 이미지, 대체 면).
- 카드·점수판·준비 중 표시·하단 탭 구조는 V07-A 그대로.

## 시각 계층·강조
- 배너만 어두운 경기장 분위기, 나머지는 흰 카드 목록(RX-002-23). 강조색은 틸 하나로 모으고 청팀 파랑과 섞지 않음.

## 진부한 기본값 대조
- 배너 전체를 어두운 그라데이션으로 덮지 않음(이미지 왼쪽이 이미 어두움). 모바일 글자 띠만 이미지 윗부분과 이어지게 짧은 그라데이션을 씀.
- 데스크톱 설명 둘째 줄은 레퍼런스와 같은 자리(밝은 코트 바닥·라인 위)라 배경 픽셀 기준 대비가 2.47:1까지 떨어짐 → 그래픽이 없는 왼쪽 아래(배너 폭 44% 안)에만 hero.bg 타원 그늘을 깔아 4.69:1 이상(배경 99% 기준). 이미지 파일은 바꾸지 않음.

## 다른 시안과의 차이
- 수정 라운드(시안 1개). 기준 V07-A와 다른 점은 배너(이미지 1장 + HTML 글자)와 초록 → 틸 색 4개.
