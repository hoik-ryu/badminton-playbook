# V05-B 디자인 계획 — 밴드·구획형(SCR-102·103)

## 시각 개념
- 사용자 결정(2026-11-19): 코트 색은 기존 초록 #2F7D4F 확정, 민트 코트 제외. 좌표·6칸·9칸·상태 전환·학습 로직 고정. V04-A 디자인 시스템을 화면 셸에 적용하되, A와 달리 카드·그림자를 줄이고 "띠(band)와 구분선"으로 영역을 나눈다.
- SCR-102: 상단 바 아래쪽에 상황 5칸 진행 띠(지난 상황 primary, 현재 상황 mint), 상황 설명은 민트 안내 띠, 판정은 아래 영역 안 상태색 띠. SCR-103: 카드 없이 가운데 정렬 큰 점수 + 구분선 구획.
- 코트 오버레이는 A와 같은 VD-026–031 값(코트 표현은 시안 간 차이가 아님).

## 색·토큰
- A와 같은 V04-A 후보 테마. 새 토큰 없음. `color.accent.mint`는 진행 띠의 현재 상황 표시(장식 면)에만 쓰고 숫자 '상황 n/5'를 늘 함께 표시.

## 타이포그래피
- 상단 바: 과정·단계 13 secondary, '상황 n/5' 16 bold, '점수 n' 16 accent. 질문·판정 제목 16 bold(A보다 한 단계 작게), 이유 13 primary.
- 결과 점수 48px(`font.size.display` × 1.5, 토큰 밖 값 후보) 가운데 정렬. CTA 22px bold.

## 간격·밀도
- 좌우 12px(A 16), 아래 영역 높이 140px 고정(A 156) → 코트가 A보다 약간 큼. 버튼 52px(ST10 도구 막대 56px).
- 결과 화면은 카드 간격 대신 구분선 + 위아래 12–14px.

## 컴포넌트 표현
- CMP-026: 한 줄(나가기·과정·상황·점수) + 아래 4px 진행 띠 5칸(장식, 숫자 병기).
- CMP-001: 큰 CTA(그림자 없음), 작은 주 버튼(outline), 보조(secondary), ST10은 아이콘 위·글자 아래 도구 버튼 4칸(tool·tool-primary).
- CMP-046: A와 같음. CMP-022·049·030·023: A와 같은 규칙, 결과 화면에서는 카드 테두리·그림자 없음.

## 시각 계층·강조
- SCR-102: 진행 띠로 '몇 번째 상황인지'를 첫눈에, 판정 띠의 상태색 면이 결과를 가장 강하게 알림(A는 아이콘 원 + 글자만 색).
- SCR-103: 가운데 큰 점수 → 통과 배지 → 기준 → (구분선) 최고 점수 → 진행률 → 틀린 상황 → 버튼.

## 진부한 기본값 대조
- 진행 띠는 장식으로만 쓰고 정보는 숫자로 함께 표시(막대만으로 전달하지 않음).
- 결과 화면을 카드 나열로 만들지 않고 한 장의 문서처럼 구획을 나눔.
- (엔진 정보 순서 검사) A와 같이 SCR-102 DOM은 본문 → 아래 영역 → 상단 바 순, CSS grid로 상단 바를 위에 배치. 구현 시 DOM 순서 확인 항목.

## 다른 시안과의 차이
- A: 둥근 흰 시트·카드·그림자, 왼쪽 정렬, 여백 넓음, ST10 재생 컨트롤은 칩 2개 + 버튼 2개 두 줄. B: 평면·구분선·상태색 띠, 결과 가운데 정렬, 여백 좁음, ST10은 4칸 도구 막대 한 줄.
