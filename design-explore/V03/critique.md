## V03-A
- **계획 대비**: V02-A의 배치·순서·행 높이(약 56px)·썸네일 크기(78×46→80×48)를 유지하고 목표 3개만 고쳤다. G1 민트 색감·배너 그라데이션, G2 스테이지별 다른 일러스트, G3 작은 글자 13px·360px 넘침 방지.
- **정보 계층**: 배너(소개·전체 진행) → 이어서 하기 → 과정 → 스테이지 행 순서는 그대로다. 최고 점수를 상태 배지 안('통과 5/5', '미완료 2/5')으로 옮겨 학습 목표 줄이 한 줄로 정리되고, 상태와 점수를 한눈에 읽는다.
- **강조**: 배너가 왼쪽 위 밝은 민트(#8EE3CC)에서 연민트·흰색으로 퍼져 V02-A보다 화사하다. 진한 Teal(#087F73)은 막대·재생 아이콘·현재 탭·배지 글자에만 남아 강조가 분산되지 않는다.
- **밀도**: 390×844 첫 화면은 V02-A와 같은 수의 행이 보인다(행 5개+과정 머리 2개). 360×640에서도 행 2개+다음 과정 머리로 V02-A와 같다. 행을 키우지 않았다.
- **제품 정체성**: 썸네일 8개가 번호 칸·기본 자리 복귀·나란히 수비+방패·좌우 담당 영역·라켓 리시브·앞뒤 공격·공격→수비 두 장면·전환+좌우 화살표로 서로 달라, 스테이지 내용이 그림만으로 구분된다.
- **진부한 기본값**: 같은 모양 행 카드 반복은 남아 있지만 썸네일 구성이 모두 달라 반복감이 V02-A보다 줄었다. 그림자는 회색 대신 Teal 기운의 옅은 그림자로 바꿔 기본 카드 느낌을 덜었다.
- **결함 후보**: ① (V03-2에서 해결) 셔틀콕을 사용자 제공 이미지(AST-026, 배경 제거본)로 바꿔 원본과 같은 사진풍 3D·깃털 질감이 됐다. 다만 원본보다 작게(104px) 두어 존재감은 원본보다 약하고, 코르크 아래 가장자리에 분리 흔적이 확대 시 약간 보인다. 권리(원작자·라이선스) 미확인. ② 썸네일 속 작은 글자('기본 자리', '앞', '뒤', '공격', '수비')는 장식이라 13px 규칙 밖이지만 실제 크기에서 거의 읽히지 않는다 — 빼거나 아이콘으로 바꾸는 것을 검토. ③ 맨 마지막 행 학습 목표('수비에서 공격으로 전환과 좌우…')는 한 줄 말줄임 처리되어 전체 문구가 목록에서 보이지 않는다. ④ 배지 글자 색은 대비를 위해 Teal 80%+본문색 혼합(약 5.4:1)이라 원본보다 약간 어둡다. ⑤ 파일로 직접 열면 탭 아이콘(CSS 마스크)이 보이지 않는다(로컬 서버 필요).
- **요구사항 밖 요소**: 없음. 정보·행동을 더하지 않았고, 점수는 기존 info-5 항목(최고 점수)의 표시 위치만 바꿨다. 아래 '상태 예시(ST4)'는 비교용 표시다.
- **시안 간 차이**: 이번 라운드는 V02-A 수정안 1개다. V02-A 대비 색(Primary #087F73·Mint #8EE3CC·Soft Mint #DDF8EF·Page #FAFFFD), 배너 그라데이션, 셔틀콕(AST-002→017→사용자 제공 AST-026), 배너 그라데이션 방향(V03-2: 왼쪽 위 연민트 → 오른쪽 아래 밝은 민트, 셔틀콕 뒤가 더 진함), 썸네일(AST-003–010→018–025), 작은 글자 11–12.5px→13px, 배지에 점수 포함, 학습 목표 한 줄 말줄임.
- **화면 간 일관성**: 대상 화면이 SCR-101 하나라 해당 없음. 같은 화면 안에서 카드 모서리·그림자·배지 높이(20px)·글자 크기 단계가 일관된다.
- **레퍼런스 대비**: 원본의 밝은 민트 배너·흰 빛줄기·오른쪽 위 셔틀콕·배너 안 진행률 카드, 과정 머리 장식 아이콘과 알약 진행 배지, 흰 행 카드와 시간 알약·화살표, 하단 탭 구성을 V02-A보다 원본 색감에 가깝게 맞췄다(RX-001-01·02·03·18).
- **레퍼런스와 다른 점**: 문구, 과정·스테이지 수(3과정 8스테이지), 맞춤 추천 대신 이어서 하기(흰 카드), 상태 배지+점수, 원본의 3D 셔틀콕·썸네일 그림 대신 새로 그린 SVG, 도움 아이콘 없음. 원본 썸네일은 아이콘형(체크리스트·라켓·방패)과 코트형이 섞였고, V03은 모두 코트 기반 전술 그림이다.
- **레퍼런스 자산 미사용**: 원본 이미지·잘라 낸 조각을 쓰지 않았다. 썸네일·과정 아이콘은 새로 그린 SVG(AST-011–013·018–025), 셔틀콕은 사용자 제공 이미지에서 배경을 뺀 PNG(AST-026, 배너 배경은 CSS), 탭 아이콘은 Lucide v1.70.0(ISC, AST-001·014–016). 리뷰 페이지의 원본 비교 조각은 비교용 표시이며 시안에 넣지 않았다.
