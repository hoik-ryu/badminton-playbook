사용자 지시(원문 발췌): "VD-026–031(SCR-102): 별도 시각 탐색 후 승인 / VD-037(SCR-103): 별도 시각 탐색 후 승인 / SCR-102·103은 기존 승인된 UX Spec의 화면 구조, 사용자 흐름, 학습 목표, AC를 반드시 준수하세요." 이 문서는 계획이며 승인 대상이 아닙니다.

## 1. 승인된 UX Spec r4 기준 화면 구성(바꾸지 않음)

### SCR-102 스테이지 플레이 (`/tutorial/stages/:stageId`, 독립 화면, 탭바 숨김)
- 배치: 상단 바 56px('나가기'·과정·단계·상황 n/5·점수) → 상황 설명 1–2줄 → 코트(CMP-046, 남은 높이 채움) → 아래 영역(질문 한 줄 + 버튼 한 줄 56px, 높이 고정, UXD-081)
- 정보 순서: ① 코트·내 편 번호 격자 ② 질문 ③ 판정 뒤 표시(고른 칸·정답 칸·허용 칸·셔틀 방향, 결과 문구) ④ 진행 n/5·점수
- 상태: ST1 선택 대기, ST2 로딩, ST4 오류, ST5 권한 없음, ST7 정답, ST8 허용, ST9 오답, ST10 정답 움직임 보기, ST11 입문자 안내형, ST12 칸 선택됨·확정 대기
- 컴포넌트: CMP-026, CMP-046, CMP-001, CMP-022, CMP-027
- 고정 조건: 코트 좌표(0–61 × 0–134, 네트 y=67)·선수·셔틀 그림·이동 애니메이션·`Choice.to` 재사용, 그리는 순서(코트 → 격자 → 강조·판정 → 선수·셔틀 → 번호 → 누름 영역), 정답·허용·오답은 색 + 아이콘 + 문구 + 선 모양, 확대 없음, 시간 제한 없음
- 관련 AC: AC-090·091·092·095·111·112·113·114·115·116·119

### SCR-103 스테이지 결과 (`/tutorial/stages/:stageId/result`, 독립 화면, 탭바 숨김)
- 정보 순서: ① 이번 점수·통과 여부(기준 '5개 중 4개(70%)' 표시) ② 최고 점수(갱신 표시) ③ 과정·전체 진행률(저장 뒤) ④ 틀린 상황 목록 ⑤ '다음 스테이지'·'다시 하기'·'목록'
- 상태: ST1 통과, ST2 저장 중(결과 먼저, 진행률은 저장 뒤), ST4 저장 실패(안내 상자 + '다시 저장', 진행률 숨김), ST7 미통과('통과까지 n점', '다시 하기' 강조)
- 컴포넌트: CMP-026, CMP-030, CMP-046, CMP-049, CMP-001, CMP-023
- 관련 AC: AC-092·094·120

## 4. 화면별 탐색 범위(제안)
- **라운드**: 새 시각 탐색 라운드 1개(예: V05, `explore-init --phase visual --targets SCR-102,SCR-103`). V04의 수정 라운드가 아니므로 수정 상한과 무관합니다.
- **시안 2개(색만 다르면 안 됨 — distinct_axes)**
  - A: **기존 초록 코트 유지**(#2F7D4F) + V04-A 셸(밝은 페이지·흰 카드·민트 배지). 코트 VD 대비값 그대로.
  - B: **민트 톤 코트**(예: 바닥을 V04 썸네일 계열 청록으로) + 같은 셸 + 아래 영역 카드형. `color.court.surface`는 04에 있는 토큰이라 값 변경은 ③(테마)이지만, VD-026–029 대비를 전부 다시 계산해야 하며 흰 격자·흰 번호 3:1 이상을 유지해야 함.
- **SCR-102 렌더 상태**: ST1(6칸 왕초급·9칸 초급), ST11(입문자 안내 문구), ST12(확인 단계), ST7, ST8, ST9, ST10. 측정 폭 390×844·360×640(코트 배율이 가장 작은 경우 확인).
- **SCR-103 렌더 상태**: ST1(통과·최고 점수 갱신·진행률 2개·틀린 상황 1개), ST7(미통과), ST2(저장 중), ST4(저장 실패).
- **확인 항목**: 코트 위 대비(격자·번호·강조·판정 아이콘), 아래 영역 높이 고정과 버튼 22px, 상단 바 정보 밀도(360px에서 한 줄), 결과 화면 위계(점수 → 통과 → 진행률 → 틀린 상황 → 버튼), 움직임 줄이기 시 표시.

## 6. 엔진 순서 제약(중요)
- 시각 단계의 활성 선택은 하나입니다. V05에서 `explore-choose`를 하면 V04 선택(EXP-V04-A)은 `superseded`가 되고, `explore-adopt`는 **현재 선택 라운드만** 채택합니다.
- 따라서 순서: ① V04 `explore-adopt`(후보 VD·후보 테마 생성) → ② V05 라운드 생성·제작·측정·선택 → ③ V05 `explore-adopt` → ④ VD 승인·제외 → ⑤ DD 제출.
- DD 제출 조건: 최신 선택(V05)을 근거로 한 VD가 07에 있어야 함. V04로 만든 VD도 그대로 유지 가능.
- 측정 설정(뷰포트 등)은 V04 채택 전에는 바꾸지 않습니다(측정 기준 변경 방지).
