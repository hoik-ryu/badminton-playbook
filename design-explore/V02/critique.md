측정 명령이 없어 자동 측정은 미실행입니다. 근거는 Claude가 로컬 HTTP(127.0.0.1)로 연 페이지를 헤드리스 Chrome으로 캡처한 화면입니다(390×844·360×640, 원본 REF-001 왼쪽 화면을 390폭으로 환산해 나란히 배치). 측정(measured)이 아닙니다.

## V02-A
- **계획 대비**: 원본 순서(제목 → 민트 배너+진행률 카드 → 과정 머리 → 스테이지 행 카드 → 하단 탭)와 비율을 따랐다. 승인 구조 때문에 배너 바로 아래에 '이어서 하기' 흰 카드가 들어간 점만 원본과 다르다.
- **정보 계층**: 배너(소개·전체 진행) → 이어서 하기 → 과정 순으로 읽힌다. 상태 배지(통과·미완료·아직 안 함)가 제목 옆에 붙어 행이 두 줄로 유지된다.
- **강조**: Teal은 막대·배지 글자·재생 아이콘·현재 탭에만 쓰여 원본처럼 차분하다. 이어서 하기는 흰 카드+그림자로 떠 보이되 튀지 않는다(사용자 지시).
- **밀도**: 390×844 첫 화면에 스테이지 행 5개+과정 머리 2개(원본은 행 6개+맞춤 추천). 행 높이 56px(원본 약 52px)로 거의 같다. 360×640에서는 행 2개+다음 과정 머리.
- **제품 정체성**: 원근 미니 코트 일러스트가 '배드민턴 위치 학습'임을 원본의 일반 아이콘보다 더 직접 보여 준다.
- **진부한 기본값**: 같은 모양 행 카드가 8개 반복되지만, 미니 코트마다 선수 배치·화살표가 달라 반복감이 줄었다.
- **결함 후보**: ① 셔틀콕이 원본보다 밝고 평면적이며 깃털 질감이 약하다. ② 미니 코트가 모두 같은 원근·색이라 원본 썸네일(아이콘형·코트형 혼합)보다 단조롭다. ③ 360px에서 긴 학습 목표('코트와 번호 익히기 · 최고 5/5')가 두 줄로 넘친다. ④ 글자 크기 일부(11–12.5px)가 04 caption(13px)보다 작아 접근성 검토가 필요하다. ⑤ 파일로 직접 열면 하단 탭 아이콘(CSS 마스크)이 보이지 않는다(로컬 서버로 열어야 보임).
- **요구사항 밖 요소**: 없음. 맞춤 추천·도움 아이콘은 넣지 않았다. 아래쪽 '상태 예시(ST4)'는 비교용 표시다.
- **시안 간 차이**: B보다 행·썸네일이 작아 원본 밀도에 더 가깝다.
- **화면 간 일관성**: 대상 화면이 SCR-101 하나라 해당 없음. 같은 화면 안에서 배지·카드 모서리·그림자 규칙이 일관된다.
- **레퍼런스 대비**: 배너(민트 방사형 그라데이션·흰 빛줄기·오른쪽 위 셔틀콕·배너 안 진행률 카드), 과정 머리(색 장식 아이콘·굵은 이름·설명·알약 진행 배지), 행 카드(왼쪽 썸네일·굵은 제목·회색 설명·시간 알약·화살표), 하단 탭(아이콘+글자, 현재 탭 Teal)을 원본과 거의 같은 크기·간격으로 맞췄다.
- **레퍼런스와 다른 점**: 문구(SMAPSH 위치 학습 등), 과정당 스테이지 2·3개와 8개 총수, 맞춤 추천 대신 이어서 하기(흰 카드), 행에 상태 배지·최고 점수 추가, 원본의 3D 셔틀콕·썸네일 그림 대신 새로 그린 SVG, 도움 아이콘 없음.
- **레퍼런스 자산 미사용**: 원본 이미지·잘라 낸 조각을 쓰지 않았다. 셔틀콕·미니 코트·과정 아이콘은 새로 그린 SVG(AST-002–013), 탭 아이콘은 Lucide(AST-001·014–016).

## V02-B
- **계획 대비**: A와 같고 스테이지 행(70px)·썸네일(98×58)·제목(15.5px)만 키웠다.
- **정보 계층**: A와 같다. 썸네일이 커서 행마다 일러스트가 먼저 눈에 들어온다.
- **강조**: A와 같다.
- **밀도**: 390×844 첫 화면에 행 4개, 360×640에서 행 2개. A보다 스크롤이 길다.
- **제품 정체성**: 미니 코트의 선수 위치·이동 화살표가 더 잘 보여 학습 내용 미리보기 역할이 강하다.
- **진부한 기본값**: A와 같다.
- **결함 후보**: ① 원본보다 행이 높아 원본 밀도와 차이가 난다. ② 360px에서 학습 목표 줄이 두 줄로 넘치는 경우가 A보다 많다(썸네일이 넓어 글자 폭이 줄어듦). ③ 셔틀콕·아이콘 문제는 A와 같다.
- **요구사항 밖 요소**: 없음(A와 같은 비교용 표시만).
- **시안 간 차이**: A 대비 행 56→70px, 썸네일 78×46→98×58, 제목 14.5→15.5px.
- **화면 간 일관성**: 대상 화면이 하나라 해당 없음. A와 같은 규칙.
- **레퍼런스 대비**: 배너·과정 머리·카드·탭은 A와 같이 원본을 따랐다. 썸네일은 원본(약 79×44)보다 크다.
- **레퍼런스와 다른 점**: A와 같고, 행·썸네일이 원본보다 크다.
- **레퍼런스 자산 미사용**: A와 같다.
