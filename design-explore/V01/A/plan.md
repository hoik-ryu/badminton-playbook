# V01-A 디자인 계획(frontend-design 절차: 계획 → 진부한 기본값 대조 → 제작 → 스크린샷 자기 비평)

## 시각 개념
- REF-001(왼쪽 튜토리얼 화면)에 최대한 충실한 안. 흰 바탕 + 민트·Teal 한 계열, 부드러운 소개 배너 안에 전체 진행률을 겹쳐 두고, 과정 머리(카드 밖) 아래 스테이지 행 카드를 쌓는다. 승인된 SCR-101·SCR-102 구조(정보 순서·행동)는 그대로.

## 색·토큰
- 공식 테마 값 그대로(color.action.primary #006D68 — RX-001-02와 가까움). 연민트 면은 CR-011 미확정이라 시안 검토용 임시 토큰 color.accent.subtle(#DFF5F1, RX-001-03)으로만 쓴다(04 밖 → token_needs_cr 경고, 공식 반영 안 함). 카드 테두리는 기존 color.border.default 유지(CR-013 B).
- 코트 위 표시는 VD-026–031 후보: 흰 점선 격자 70%, 판정 채움 = 상태 배경 90% + 상태 글자색 번호 원.

## 타이포그래피
- 승인 토큰만: 페이지 제목 font.size.heading(22) 800, 배너 제목 heading 800 두 줄, 과정 이름 title(18) 700, 스테이지 제목 body(16) 700, 보조 caption(13). 숫자(진행·시간)는 굵게 + 고정폭(RX-001-09, VD-004). RX-001-08의 큰 제목 크기(약 28px)는 참고 수준이라 쓰지 않음.

## 간격·밀도
- 넉넉한 여백: 좌우 20px(space.5), 섹션 사이 32px(space.8), 행 카드 사이 10px, 행 높이 76px. RX-001-17은 참고 수준이라 수치는 기존 space 토큰에서 고름.

## 컴포넌트 표현
- CMP-049 진행률: 8px 둥근 막대 + '3 / 8' 숫자(RX-001-13). CMP-050 이어서 하기: 연민트 카드 + 원형 재생 아이콘(RX-001-15 표현만). CMP-048 과정: 카드 밖 섹션 머리(아이콘·이름·설명·알약 배지, RX-001-06·14) + 행마다 흰 카드(CMP-047, RX-001-11). 썸네일은 CR-012 A(미니 코트, 장식). 준비 중은 점선 카드.
- SCR-102: 기존 TutorialCourt 좌표계를 CSS로 다시 그린 코트 + 번호 격자 오버레이(시안에서는 인라인 SVG 금지 규칙 때문에 CSS). 아래 영역은 연민트 패널.

## 시각 계층·강조
- 1순위 '이어서 하기'(연민트 면 + Teal 아이콘), 2순위 배너의 전체 진행률, 3순위 과정 머리. 진한 Teal 면은 막대 채움·주 버튼에만(RX-001-18).

## 진부한 기본값 대조
- 같은 모양 카드 나열이 되지 않도록 과정 머리는 카드 밖 섹션 제목으로, 스테이지 행만 카드로 구분. 의미 없는 번호 라벨 대신 학습 목표 제목을 앞세움. 이미지의 '맞춤 추천'·도움 아이콘·3D 셔틀콕은 쓰지 않음(범위 밖·자산 미사용).
- SCR-102에서 '정보 순서'는 승인 우선순위(코트 → 질문 → 판정 → 진행)로 HTML에 두고, 상단 바는 CSS order로 위에 보이게 함(화면 읽기 순서는 승인 우선순위).

## 다른 시안과의 차이
- B보다 여백·카드 수가 많고(행 카드 개별), 강조를 연민트 면으로 부드럽게 분산. B는 과정 하나를 카드 하나로 묶고 행을 평평하게 해 밀도를 높이며, 이어서 하기 한 곳만 진한 Teal 면으로 강하게 강조.
